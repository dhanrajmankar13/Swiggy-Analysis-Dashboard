# Swiggy Sales Analysis Dashboard

## Project Overview

This Excel Dashboard project analyzes Swiggy food delivery sales data to identify sales trends, customer behavior, restaurant performance, and regional demand patterns.

The dashboard provides interactive insights that help businesses monitor KPIs, track performance, and support data-driven decision-making.

## Dashboard Insights

### Monthly Sales Trend
- Sales remained stable throughout the year.
- Peak sales observed in August.

### Daily Sales Trend
- Highest sales recorded on Saturday.
- Weekend demand is stronger than weekdays.

### Food Category Analysis
- Vegetarian orders contribute approximately 64% of sales.
- Non-Vegetarian orders contribute approximately 36%.

### State-wise Analysis
- Maharashtra generated the highest sales.
- Strong demand observed across major Indian states.

### Top Cities by Sales
1. Bengaluru
2. Lucknow
3. Hyderabad
4. Mumbai
5. New Delhi
